Como funciona

Para cada pergunta, um orquestrador planeja os passos, usa as ferramentas e só responde depois de conferir que cada número aparece nos resultados.

O que protege os dados e o serviço

SQL só leitura
Um único SELECT por chamada. Escrita, vários comandos e leitura de arquivos são recusados antes de rodar. Limite de 30 s.
Python isolado
Roda no seu navegador, em WebAssembly, num Worker sem rede e sem acesso à página. Limite de 30 s.
Números conferidos
Cada número da resposta precisa bater com os resultados das ferramentas, com margem de 1%. Se não bater, o agente refaz a análise até 2 vezes.
Limites
No máximo 8 ferramentas, 12 chamadas ao modelo e 120 s por pergunta. Uma pergunta por vez, com teto diário.
Memória curta
Lembra as 3 últimas perguntas da sessão, para entender "e só em São Paulo?". Nova conversa apaga tudo.
Dado pessoal fica de fora
Colunas que parecem CPF, e-mail ou telefone são marcadas e ficam fora do perfil enviado à IA. A IA é instruída a só agregá-las, mas os resultados das consultas não são mascarados. Não envie dados pessoais reais.

Decisões técnicas

  • A resposta chega por streaming (SSE), com plano, ferramentas e conferência visíveis.
  • Os gráficos são desenhados no navegador a partir de dados moldados pelo servidor.
  • O modelo troca por variável de ambiente, e há um modelo reserva.
  • Com a cota esgotada, os exemplos reproduzem uma gravação marcada como tal.

Projeto de portfólio. Os dados de exemplo são fictícios e não vêm de nenhuma empresa.
